# photoMan

一個**本地優先**的修圖工具，讓不懂專業修圖軟體的人也能改圖：
用滑鼠圈出要改的地方，AI 只改那一塊，**本機負責合成**。

> **鐵律：圈選範圍以外，像素逐 bit 不變。**
> 改了很多處之後也一樣——**所有圈選範圍的聯集之外**，逐 bit 等於原檔。

## 為甚麼需要這個工具

用對話式 AI 改圖有兩個常見的痛點：

1. **很難仔細指定要修哪一部分。** 文字是低頻寬的空間描述語言——
   「把左邊那個人手上的膠袋拿走」，模型必須先猜「膠袋」指的是哪一團像素。
   空間問題要用**滑鼠**解決，不是用更長的提示詞。
2. **輸出尺寸不等於細節保留。** AI 可能交回比原圖小的圖片；放大至 4K
   不會恢復原有的石紋、樹枝等細節。模型及使用工具會影響實際輸出尺寸，
   因此需要檢查交回的圖片，不能只看匯出檔案的像素尺寸。

## 做法

```
使用者圈選區域          ← 空間通道：筆刷、方框，或點擊分割
      ↓                  手畫的範圍就是遮罩，不經模型判斷
      ↓
本機在原解析度裁出該區域（含一圈校驗環作上下文）
      ↓
只送這一小塊給模型
      ↓
檢查輸出尺寸 → 需要放大時先取得確認
      ↓
量度校驗環，記錄模型在周邊的差異
      ↓
色彩／顆粒對齊
      ↓
只貼回遮罩範圍內 —— 遮罩以外從未被寫入
```

**為甚麼這件事只能靠本地合成。** 模型廠商自己承認會漂移：
FLUX.1-Fill-dev 的官方模型卡寫明填充區以外有輕微色偏、填充區邊緣有線條；
diffusers 的維護者說明 inpaint 權重是**刻意**訓練成跨接縫融合的。
所以這條保證必須是合成器的架構性質，不是關於任何模型的聲明。

## 開始使用

**第一次：**

```powershell
setup.bat
```

它會建立 Python 環境、安裝依賴、下載模型（約 140 MB）、
在桌面建立捷徑，並跑一次測試確認一切正常。**可以重複執行**，
已完成的步驟會自動跳過。

**之後：** 雙擊桌面的 `photoMan` 捷徑，或 `photoMan.bat`。

瀏覽器會自動開啟。流程是：**拖入照片 → 圈出要改的地方 → 按「執行」
→ 前後對照 → 匯出**。

**可以連續改很多處。** 每一次執行都直接生效，成品成為下一個編輯的底圖，
不滿意按「復原」（它會把你當初圈的範圍放回來，方便改一改再試一次）。
修改會自動存起來——關掉瀏覽器再開同一張照片，進度還在。

**匯出**預設是 WebP。理由很實際：PNG 存照片是浪費——同一張 18.4 MP 的圖
（原檔 JPEG 5.05 MB），PNG 是 17.32 MB，WebP 是 **3.49 MB**，
而平均只差 0.95 級。要完全不失真的人可以改選 PNG。

圈選有三種工具，**預設是手動的**：

| 工具 | 用法 |
|---|---|
| 筆刷 | 拖曳塗抹，粗細可調 |
| 方框 | 拉一個矩形 |
| 自動 | 點一下物件，由 MobileSAM 判斷邊界 |

**移動與縮放：** 滾輪縮放，**按住滑鼠中鍵拖曳**移動畫面。
縮放列在畫布左上方，百分比是相對原圖的——100% 就是原圖一個像素對螢幕
一個像素。放大之後畫面會自動改由原檔取樣，所以你看到的是真正的像素。

筆刷與方框畫出來的範圍**就是遮罩本身**，中間不經過任何模型判斷——
你畫到哪裡就改到哪裡。按「自動」才會交給分割模型。

**修改整張圖：** 按第一步的「全選」，會選取原圖每一個像素；再輸入指令並
選擇 Codex 或雲端模型執行。按「清除選取」可取消全選，不需要下載分割模型。

**本機 Codex（無需 API key）：** 電腦已安裝 Codex 桌面版或 CLI，並以 ChatGPT
登入時，模型選單會出現「本機 Codex」。圈選範圍、填寫指令、選擇此模型後按
「執行」即可自動生圖並合成，不需要手動匯出或匯入。

此功能會使用 Codex 額度；圖片仍由雲端生成，只有裁切區域、圈選提示與所附
參考圖會交給 Codex。每次通常需要 1–3 分鐘，最長等候 10 分鐘。
photoMan 不讀取或複製登入憑證，沿用 CLI 的 ChatGPT 登入；失敗時會顯示錯誤。
請先用 `codex login status` 確認登入，CLI 需支援內置 `image_generation` 工具。

**尺寸與清晰度：** 裁切圖、圈選提示及參考圖均按原尺寸傳送，取消原先 1536
長邊的預先縮圖。若 AI 交回的圖片在任何一邊小於處理範圍（包含周邊參考），
會先顯示輸出尺寸、需要貼回的尺寸及放大倍率，讓你選擇接受或取消。
確認接受才放大並合成，直接使用已生成的圖片，不會再次生成；取消會保留
目前照片及選取範圍。模型仍可能自行縮小輸入或產生較小圖片，原尺寸傳送
不代表模型一定交回相同尺寸。此檢查同樣適用於 OpenRouter 圖像模型。

**雲端模型（BYO API key）：** 在第二步描述你想做甚麼，模型就會照做，
也可以附參考圖。它是用來**換成別的內容**的（改衣服顏色、加東西）——
這些事本機的 LaMa 做不到。

- **只是要移除東西的話，用本機。** 免費、原解析度、遮罩原生，
  而且顏色與周圍對得準（實測差 0.7 級，雲端是 11–25 級）。
- **用雲端時框得越緊越好。** 這些 API 沒有遮罩參數，它會重畫你框起來的
  整個範圍——框一大片，它就用自己理解的內容重畫一大片。
  模型有沒有照遮罩辦事，成品下方會告訴你。

> ⚠️ `.bat` 檔**必須保持純 ASCII**。從檔案總管雙擊時 console 是
> OEM 437，非 ASCII 字元會變亂碼；而加 `chcp 65001` 去補救會令
> cmd 的檔案位移錯亂。所以那兩個檔案裡的訊息一律用英文。

**命令列：**

| 指令 | 用途 |
|---|---|
| `photoman ui` | 開啟介面 |
| `photoman models` | 檢查模型檔案的狀態 |
| `photoman shortcut` | 重建桌面捷徑 |

## 開發

```powershell
py -3.12 -m venv .venv          # 必須 py -3.12，PATH 上的 python 不是 3.12
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"

.\.venv\Scripts\python.exe -m pytest -q
```

**所有指令一律用 `./.venv/Scripts/python.exe`**，或在專案內使用 `py -3.12`。

## 開發慣例

- 所有文件、註解、介面文字一律**書面語中文**，不使用廣東話口語。
  程式碼標識符與技術術語保持英文。
- **註解解釋「為甚麼」，不解釋「做什麼」。**
- `src/photoman/composite.py` 與 `mask.py` 的任何改動都必須有對應測試——
  那兩個檔案是本案的保證所在。
